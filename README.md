# afchistory
A Wikipedia tool for displaying a user's history of [Articles for Creation](https://en.wikipedia.org/wiki/Wikipedia:WikiProject_Articles_for_creation) reviews.

Check it out at https://apersonbot.toolforge.org/afchistory/ or https://enterprisey.github.io/afchistory/.

## developers

The git main branch is named gh-pages.

Pushing to gh-pages auto deploys to https://enterprisey.github.io/afchistory/.

https://apersonbot.toolforge.org/afchistory/ has to be deployed manually, and is the link that many Wikipedians use.
